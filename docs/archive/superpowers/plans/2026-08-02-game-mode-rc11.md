# Game Mode RC11 Implementation Plan

> **For agentic workers:** Implement task-by-task. Spec: `docs/design-game-mode-rc11.md`.

**Goal:** Ship a terminal-native, animated office view (`Shift+G`) showing the Supervisor + up to 6 subagent desks, with composer retained, resize tiers, and handoff/spawn beats.

**Architecture:** Self-contained `views/game_mode/` (layout, state, sprites, anim, wall, render) owned by `AgentView::game_mode`. Toggle replaces scrollback region with the office; prompt/composer path unchanged. Subagent sync from `subagent_sessions` each tick/frame.

**Tech Stack:** ratatui, crossterm, existing `SubagentInfo` / action registry.

## Acceptance (from spec §10)

1. Shift+G toggles; composer works  
2. 6 desks / IDLE empty  
3. Monitor stats when space  
4. Wall WORKING / STANDBY / WORK FINISHED  
5. Handoff on success (or Compact flash)  
6. Door spawn when not Compact  
7. Resize safe  
8. Compact fallback  
9. Fail ≠ handoff  
10. Shortcuts document Shift+G
