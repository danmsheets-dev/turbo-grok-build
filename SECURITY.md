# Security Policy

This repository is an **unofficial community fork** of
[xAI Grok Build](https://github.com/xai-org/grok-build), maintained at
[danmsheets-dev/turbo-grok-build](https://github.com/danmsheets-dev/turbo-grok-build).

It is **not** affiliated with, supported by, or covered by xAI. **Do not**
report vulnerabilities in this fork to [xAI's HackerOne program](https://hackerone.com/x).
That program cannot patch this tree.

## Reporting a vulnerability

Use GitHub private vulnerability reporting on this repository:

https://github.com/danmsheets-dev/turbo-grok-build/security/advisories/new

Do not open a public GitHub issue for security reports.

If the private-reporting form is unavailable, open a draft security advisory
from the repository **Security** tab. Include the affected version (`turbo
--version` / `VERSION`) and a minimal reproduction. Do not attach exploit
payloads.
